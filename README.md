# C Lab

A collection of C programs covering data structures and algorithms.

## Contents

The source files are located in the `lab` folder and include implementations of:

- Linked lists
- Stacks and queues
- Binary trees
- DFS and BFS
- Polynomials
- Infix, postfix, and prefix expressions
- Recursive traversal

## Compile a Program

Use a C compiler such as GCC:

```sh
gcc "lab/bfs.c" -o bfs
```
